## 问题原因
`subscription-status.tsx` 尝试从 `localStorage` 读取 `inkwords_email`，但这个 key 从未被设置过。登录时只存储了 `inkwords_user` 对象。

## 解决方案
修改 `subscription-status.tsx` 中的 `handleManageSubscription` 函数：
1. 从 `inkwords_user` 对象中获取 email，而不是 `inkwords_email`
2. 如果获取不到 email，显示错误提示

## 修改内容
```typescript
// 修改前：
const email = localStorage.getItem("inkwords_email")

// 修改后：
const userStr = localStorage.getItem("inkwords_user")
const user = userStr ? JSON.parse(userStr) : null
const email = user?.email
```

确认后立即执行修复。
