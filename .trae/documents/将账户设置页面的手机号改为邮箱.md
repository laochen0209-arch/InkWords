# 将账户设置页面的手机号改为邮箱

## 当前问题

在 `app/settings/account/page.tsx` 中，页面显示的是**手机号绑定**功能：

```typescript
// UI 文本
phoneSection: "手机号",
phonePlaceholder: "请输入手机号",
phoneBound: "已绑定",
phoneUnbound: "未绑定",
bindPhone: "点击绑定手机号",
phoneDesc: "绑定手机号可用于账号安全验证和重要通知",
```

但项目中没有手机号接码功能，只有邮箱验证码功能。

## 修改计划

### 1. 修改 UI 文本

将所有的"手机号"相关文本改为"邮箱"：

```typescript
// 中文
phoneSection: "邮箱",  // 改为 "邮箱"
phonePlaceholder: "请输入邮箱",  // 改为 "请输入邮箱"
phoneBound: "已绑定",
phoneUnbound: "未绑定",
bindPhone: "点击绑定邮箱",  // 改为 "点击绑定邮箱"
phoneDesc: "绑定邮箱可用于账号安全验证和重要通知",  // 改为邮箱描述

// 英文
phoneSection: "Email",  // 改为 "Email"
phonePlaceholder: "Enter email",  // 改为 "Enter email"
bindPhone: "Click to bind email",  // 改为 "Click to bind email"
phoneDesc: "Binding email can be used for account security verification and important notifications",
```

### 2. 修改验证逻辑

将手机号的 11 位验证改为邮箱格式验证：

```typescript
// 修改前：
if (phoneInput.length === 11) {
  // 保存手机号
}

// 修改后：
const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/
if (emailRegex.test(phoneInput)) {
  // 保存邮箱
}
```

### 3. 修改输入框类型

将输入框类型从 `tel` 改为 `email`：

```typescript
// UI 文本
phoneSection: "手机号",
phonePlaceholder: "请输入手机号",
phoneBound: "已绑定",
phoneUnbound: "未绑定",
bindPhone: "点击绑定手机号",
phoneDesc: "绑定手机号可用于账号安全验证和重要通知",
```

### 4. 修改显示逻辑

将手机号的掩码显示（如 138\*\*\*\*8888）改为邮箱显示：

```typescript
// 修改前：
const maskedPhone = phoneInput.replace(/(\d{3})\d{4}(\d{4})/, "$1****$2$3")

// 修改后：
// 直接显示邮箱，或只显示部分（如 a***@example.com）
```

## 修改文件

* `app/settings/account/page.tsx`

## 预期效果

1. ✅ 页面显示"邮箱"而不是"手机号"
2. ✅ 输入框验证邮箱格式
3. ✅ 提示文本改为邮箱相关
4. ✅ 与项目的邮箱验证码功能一致
