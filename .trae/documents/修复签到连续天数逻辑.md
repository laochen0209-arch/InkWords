## 问题
`/home` 页面使用独立的 localStorage 签到逻辑，与其他页面不同步。

## 修复方案

### 修改文件: `app/home/page.tsx`

1. **移除 localStorage 相关逻辑**
2. **使用 `/api/checkin` API 获取和更新签到状态**
3. **与 `/checkin` 页面保持一致**

### 具体修改

**获取签到状态：**
```typescript
const checkInResponse = await fetch('/api/checkin', {
  headers: { 'x-user-email': userEmail }
})
const checkInData = await checkInResponse.json()
setStreakDays(checkInData.streak)
setChecked(checkInData.checked)
```

**执行签到：**
```typescript
const response = await fetch('/api/checkin', {
  method: 'POST',
  headers: { 'x-user-email': userEmail }
})
const data = await response.json()
setStreakDays(data.streak)
setChecked(true)
```

### 预期效果
- 首页签到与系统签到完全同步
- 所有页面显示相同的连续天数
- 用户在任何页面签到，其他页面都能正确显示
