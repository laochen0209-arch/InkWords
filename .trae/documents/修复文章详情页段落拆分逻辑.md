## 问题分析

当前代码使用句号、感叹号等标点符号拆分段落：
```typescript
en = enTxt.match(/[^.!?]+[.!?]+["']?|[^.!?]+$/g)?.map((s: string) => s.trim()) || []
zh = cZh.match(/[^。！？]+[。！？]+["']?|[^。！？]+$/g)?.map((s: string) => s.trim()) || []
```

这导致 `U.S.` 被错误拆分成多段。

## 修复方案

使用双换行符 `\n\n` 作为分隔符拆分段落：

```typescript
// 使用双换行符拆分段落
const splitByParagraph = (text: string): string[] => {
  return text
    .split(/\n\n+/)
    .map(p => p.trim())
    .filter(p => p.length > 0)
}

let en = splitByParagraph(enTxt)
let zh = splitByParagraph(cZh)
```
