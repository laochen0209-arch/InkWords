## 问题分析

错误：调用 `/api/notifications/subscribe` 返回 500 (Internal Server Error)

**根本原因**：
`app/api/notifications/subscribe/route.ts` 使用了：
```typescript
const { data: { session } } = await supabase.auth.getSession();
```

但在 Next.js Route Handler 中，`createClient` 直接使用环境变量创建的客户端**无法访问浏览器 Cookie**，导致 `getSession()` 返回 null。

## 修复方案

修改 `app/api/notifications/subscribe/route.ts`：

1. 使用 `@supabase/ssr` 的 `createServerClient` 配合 `cookies` 从 Cookie 中解析 Session
2. 如果无法获取用户，允许匿名订阅（user_id 设为 null）

## 具体修改

**文件**: `app/api/notifications/subscribe/route.ts`

```typescript
import { createServerClient } from '@supabase/ssr'
import { cookies } from 'next/headers'

const cookieStore = await cookies()
const supabase = createServerClient(
  process.env.NEXT_PUBLIC_SUPABASE_URL!,
  process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
  { cookies: { getAll() { return cookieStore.getAll() }, setAll() {} } }
)

const { data: { user } } = await supabase.auth.getUser()
// user_id 可以为 null，允许匿名订阅
```
