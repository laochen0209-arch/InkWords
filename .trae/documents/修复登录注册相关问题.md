- `app/api/auth/route.ts` 逻辑问题：用户不存在时自动创建新用户，但这应该是注册逻辑而非登录逻辑
- 缺少 `userId` 返回，导致前端无法正确存储用户状态

**修复方案**:
1. 修复 auth API：用户不存在时返回错误，而不是自动创建
2. 确保返回的数据包含 `userId`，用于存储到 localStorage
3. 修复 register API 同样的问题

### 问题 3: ERR_ABORTED 请求中断
**根本原因**: 请求在组件卸载或页面导航时被取消

**修复方案**:
1. 添加请求取消信号处理
2. 在组件卸载时清理未完成的请求
