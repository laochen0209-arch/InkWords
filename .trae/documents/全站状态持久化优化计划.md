## 优化目标
为全站关键页面添加 URL Query Parameters + LocalStorage 双重状态持久化机制

## 具体任务

### 1. /study 修习页面 (高优先级)
**需要持久化的状态：**
- `category`: Lifestyle/Professional
- `mode`: word/sentence (单词/句子模式)
- `method`: A/B (拼写/默写模式)

**实现方案：**
```typescript
// 从 URL 读取，否则使用默认值
const category = searchParams.get('category') || 'Lifestyle'
const mode = searchParams.get('mode') || 'word'
const method = searchParams.get('method') || 'B'

// 切换时更新 URL
const handleCategoryChange = (newCategory) => {
  localStorage.setItem('study_last_category', newCategory)
  router.push(`/study?category=${newCategory}&mode=${mode}&method=${method}`)
}
```

### 4. /library 图书馆 (中优先级)

## 技术规范

### URL 参数命名规范
- 使用小写驼峰或短横线连接
- 保持与变量名一致
- 示例：`?type=HSK&mode=practice`

### LocalStorage Key 规范
- 使用前缀：`inkwords_`
- 页面标识：`inkwords_study_category`
- 结构：`inkwords_<page>_<state>`

### 读取优先级
1. URL Query Parameters (最高)
2. LocalStorage (次之)
3. 默认值 (最后)

## 预期效果
- 刷新页面后保持当前选择
- 可以直接分享带状态的链接
- 浏览器后退/前进正常工作
- 提升整体用户体验
