## 问题分析

### 1. `createClient` 命名冲突
**文件**: `lib/supabase/client.ts`
**问题**: 导入的 `createClient` 和导出的函数同名，导致冲突
```typescript
import { createClient } from '@supabase/supabase-js'  // 导入
export const createClient = () => { ... }  // 导出同名，冲突！
```

**修复方案**: 将导出的函数重命名为 `createBrowserClient` 或使用不同的变量名

### 2. API 返回 HTML 而不是 JSON
**错误**: `Unexpected token '<', "<!DOCTYPE "... is not valid JSON`
**原因**: 
- API 路由 `/api/articles` 使用了 `checkLibraryQuota` 函数
- `checkLibraryQuota` 使用了 `createServerClient()` 
- 但 `createServerClient` 在 API 路由中可能有问题（服务端/客户端混淆）

**修复方案**: 
- 在 API 路由中使用 Next.js 的 `createRouteHandlerClient` 而不是自定义的 `createServerClient`
- 或者修复 `createServerClient` 的使用方式

## 修复步骤

1. **修复 `lib/supabase/client.ts`**
   - 重命名导出的函数为 `createBrowserClient`
   - 更新所有引用此文件的地方

2. **修复 API 路由中的 Supabase 客户端使用**
   - 修改 `/api/articles/route.ts` 和 `/api/study/data/route.ts`
   - 使用 `@supabase/auth-helpers-nextjs` 的 `createRouteHandlerClient`

3. **更新引用文件**
   - `app/profile/page.tsx`
   - `app/dashboard/hooks/use-dashboard-data.ts`
   - 将 `createClient` 改为 `createBrowserClient`
