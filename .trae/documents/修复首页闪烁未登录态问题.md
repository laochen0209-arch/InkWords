## 问题分析

从截图可以看到：
1. 页面顶部有红色的"请先登录"警告条
2. 控制台显示 `[Auth] 当前状态: { status: 'loading', ... }`
3. 签到按钮显示"立即签到"，但点击后会提示"请先登录"

## 根本原因

1. **`handleCheckIn` 函数在 `authLoading` 时显示 toast 错误**
   ```typescript
   if (authLoading) {
     toast.error('正在加载用户信息，请稍候...')  // 错误！
     return
   }
   ```

2. **签到按钮没有正确处理 `authLoading` 状态**
   - 按钮在 `isLoading` 时禁用，但没有考虑 `authLoading`
   - 用户可以在认证加载完成前点击按钮

3. **页面没有显示加载状态**
   - 当 `authLoading` 为 `true` 时，页面应该显示加载中，而不是允许用户交互

## 修复方案

### 1. 修改签到按钮逻辑

**方案 A：禁用按钮并显示加载状态**
```typescript
<button
  disabled={isCheckedIn || isCheckingIn || isLoading || authLoading}
  className={...}
>
  {authLoading ? '加载中...' : 
   isCheckingIn ? '签到中...' : 
   isCheckedIn ? '已签到' : 
   '立即签到'}
</button>
```

**方案 B：点击时不显示 toast，直接返回**
```typescript
const handleCheckIn = async () => {
  if (isCheckedIn || isCheckingIn) return
  
  // 如果还在加载中，直接返回，不显示任何提示
  if (authLoading) {
    return
  }
  
  if (!authUser) {
    toast.error('请先登录')
    return
  }
  
  // ... 后续逻辑
}
```

### 2. 修改页面整体加载逻辑

添加全局加载状态：
```typescript
// 如果认证还在加载中，显示全局加载
if (authLoading) {
  return (
    <div className="min-h-screen flex items-center justify-center">
      <Loader2 className="w-8 h-8 animate-spin text-[#C23E32]" />
      <span className="ml-2 text-ink-gray">加载中...</span>
    </div>
  )
}
```

### 3. 修改数据获取逻辑

确保在 `authLoading` 时不发送请求：
```typescript
useEffect(() => {
  if (authLoading) return  // 等待认证加载完成
  
  if (!authUser) {
    setIsLoading(false)
    return
  }
  
  // 获取数据...
}, [authUser, authLoading])
```

## 推荐方案

**实施方案 B + 全局加载状态**：
1. 签到按钮在 `authLoading` 时显示"加载中..."并禁用
2. `handleCheckIn` 在 `authLoading` 时直接返回，不显示 toast
3. 可选：添加全局加载状态
