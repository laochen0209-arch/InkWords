## 优化目标
为试卷页面的正确答案添加中文翻译，实现中英双语对照显示。

## 当前问题
正确答案只显示英文（如 "Traffic congestion"），没有对应的中文翻译。

## 优化方案

### 1. 正确答案双语显示格式
将正确答案区域改为两行显示：
```
正确答案 / Correct Answer: 
[英文答案] / [中文翻译]
```

### 2. 数据来源
- 优先使用数据库中的 `correct_answer_cn` 字段作为中文翻译
- 如果没有中文翻译字段，使用在线翻译或保持原样

### 3. 视觉样式
- 英文答案：默认字体，正常大小
- 中文翻译：衬线字体 `font-serif`，稍小字号，灰色
- 用 `/` 分隔中英文

### 4. 代码修改位置
修改 `QuestionPanel` 组件中的正确答案显示部分（第 102-106 行）
