# 修改账户设置页面支持重新绑定邮箱

## 需求理解

用户希望：
1. 显示当前绑定的邮箱（注册时的邮箱）
2. 支持重新绑定其他邮箱
3. 需要验证新邮箱（发送验证码）

const [email, setEmail] = useState("")

**编辑模式：输入新邮箱 + 验证码：**
```typescript
// 步骤1：输入新邮箱并发送验证码
<input
  type="email"
  value={newEmail}
  onChange={(e) => setNewEmail(e.target.value)}
  placeholder={t.newEmailPlaceholder}
/>
<button onClick={handleSendCode}>
  {isCodeSent ? t.resendCode : t.sendCode}
</button>

// 步骤2：输入验证码
<input
  type="text"
  value={verificationCode}
  onChange={(e) => setVerificationCode(e.target.value)}
  placeholder={t.codePlaceholder}
  maxLength={6}
/>

// 步骤3：确认绑定
<button onClick={handleVerifyAndBind}>
  {t.confirmBind}
</button>
```

### 3. 添加重新绑定功能

**发送验证码到新邮箱：**
```typescript
const handleSendCode = async () => {
  // 验证邮箱格式
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/
  if (!emailRegex.test(newEmail)) {
    toast.error(t.invalidEmail)
    return
  }
  
  // 调用发送验证码 API
  const response = await fetch('/api/send-code', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ email: newEmail, type: 'reset_password' })
  })
  
  if (response.ok) {
    setIsCodeSent(true)
    toast.success(t.codeSent)
  }
}
```

**验证并绑定新邮箱：**
```typescript
const handleVerifyAndBind = async () => {
  // 调用验证 API
  const response = await fetch('/api/verify-code', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ 
      email: newEmail, 
      code: verificationCode,
      type: 'reset_password'
    })
  })
  
  if (response.ok) {
    // 更新用户邮箱
    setEmail(newEmail)
    setUserData({ email: newEmail })
    setIsEditingEmail(false)
    toast.success(t.emailBindSuccess)
  }
}
```
