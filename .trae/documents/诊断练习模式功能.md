## 修复 PracticeContent.tsx 中的参数拼接问题

**问题原因：**
`getLinkWithType` 函数在处理参数时，如果路径已经包含 `?mode=xxx`，再拼接当前 URL 参数会错误地使用 `?` 而不是 `&`。

**修复方案：**
修改 `getLinkWithType` 函数，正确处理参数拼接：
1. 如果路径中有 `?`，用 `&` 连接参数
2. 如果路径中没有 `?`，用 `?` 连接参数

修改后的函数：
```javascript
const getLinkWithType = (path: string) => {
  const params = new URLSearchParams(searchParams.toString())
  const separator = path.includes('?') ? '&' : '?'
  return params.toString() ? `${path}${separator}${params.toString()}` : path
}
```

这样智能刷题和全真模考的链接就能正确传递 `mode` 参数了。
