## 优化 ExamContent.tsx UI 风格

**目标：** 统一考试页面与整个网站的 UI 风格

### 主要修改：

1. **添加山水画背景**
   - 使用 `bg-ink-paper ink-landscape-bg` 类

2. **统一颜色方案**
   - 将蓝色 (#3b82f6) 改为品牌红色 (#C23E32)
   - 背景色改为宣纸色 (#FDFBF7)
   - 文字颜色统一使用墨黑色 (#2B2B2B)

3. **优化顶部导航栏**
   - 添加毛玻璃效果 `backdrop-blur-md bg-[#FDFBF7]/90`
   - 使用衬线字体 `font-serif`

4. **优化卡片样式**
   - 添加圆角和阴影
   - 使用宣纸色背景

5. **优化按钮样式**
   - 使用品牌红色作为主色调
   - 添加阴影效果

6. **优化底部提交栏**
   - 使用毛玻璃效果
   - 统一的按钮样式
