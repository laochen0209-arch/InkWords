## 问题分析

从浏览器日志可以看到：
```
[error] [Auth] 获取用户资料失败: {message: TypeError: Failed to fetch
```

这说明 `fetchUserProfile` 函数在查询 `public.users` 表时失败了（网络错误）。

但即使获取用户资料失败，`auth-context.tsx` 第125-133行仍然会使用 Auth 的基础数据设置用户：
```typescript
setUser({
  id: authUser.id,
  email: authUser.email || '',
  ...
})
```

问题出在 `ExamContent.tsx` 的 `handlePracticeComplete` 函数：
1. 它首先检查 `authUser?.id`
2. 如果 `authUser` 为 null（可能由于网络问题导致 context 未正确设置），就会提示"请先登录"

## 修复方案

修改 `handlePracticeComplete` 函数（第1031-1112行）：

1. **改进用户ID获取逻辑**：
   - 不再依赖 `authUser`，直接使用 `supabase.auth.getSession()` 获取当前会话
   - 添加错误处理和重试机制

2. **改进错误提示**：
   - 如果是网络错误，提示用户检查网络连接
   - 如果确实未登录，提示登录
   - 如果没有更多试卷，提示"内容正在努力更新中"并返回/practice

3. **添加加载状态**：
   - 点击"完成练习"后显示加载状态，防止重复点击
