# 网站全面优化计划

## 一、代码清理与整理

### 1.1 删除废弃目录
- **删除** `01/`, `02/`, `03/`, `04/` 目录（这些看起来是备份/废弃代码）
- **删除** `.trae/documents/` 中过期的文档（保留重要的最新文档）

### 1.2 清理 console.log
- 在 22 个文件中有 console.log，需要在生产环境中移除或条件化
- 主要文件：dashboard, auth, checkin, home, register, practice 等页面

## 二、性能优化

### 2.1 扩大缓存应用范围
- 将缓存机制应用到更多 API 路由和数据获取
- 为文章、词汇表、考试数据等添加缓存

### 2.2 优化所有使用 useSearchParams 的页面
- 检查并为所有使用 useSearchParams 的页面添加 Suspense 包装
- 确保构建时没有预渲染错误

### 2.3 图片优化
- 检查所有图片资源，确保使用 Next.js Image 组件
- 优化图片加载策略（priority, sizes 等）

## 三、架构优化

### 3.1 统一数据层
- 确认 Prisma 和 Supabase 的使用策略
- 如果只用 Supabase，可以清理 Prisma 相关代码

### 3.2 API 路由优化
- 统一 API 响应格式
- 添加 API 请求限流
- 优化数据库查询（添加索引等）

### 3.3 组件优化
- 识别并优化重复组件
- 添加组件懒加载
- 优化组件重新渲染

## 四、开发体验与错误处理

### 4.1 环境变量检查
- 添加启动时的环境变量验证
- 提供清晰的错误提示

### 4.2 错误边界增强
- 为更多页面添加错误边界
- 提供用户友好的错误页面

### 4.3 TypeScript 类型完善
- 检查并完善类型定义
- 减少 any 类型的使用

## 五、具体执行步骤

1. **第一阶段**：清理废弃代码和 console.log
2. **第二阶段**：扩大缓存应用和性能优化
3. **第三阶段**：架构优化和统一
4. **第四阶段**：错误处理和开发体验改进

每项优化都会确保：
- 不破坏现有功能
- 有充分的测试
- 有清晰的文档说明
