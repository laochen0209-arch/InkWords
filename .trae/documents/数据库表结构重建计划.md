## 数据库重建计划

根据 schema.prisma 和现有 SQL 文件，需要创建以下数据表：

### 核心数据表（按依赖顺序）

1. **User** - 用户表
   - id, email, password, name, avatar, points, streak, lastLoginDate, createdAt, updatedAt

2. **Vocabulary** - 词汇表
   - id, english, chinese, pinyin, exampleEn, exampleZh, difficulty, category, createdAt, updatedAt

3. **Sentence** - 句子表
   - id, contentEn, contentZh, pinyin, author, category, createdAt, updatedAt

4. **Article** - 文章表
   - id, titleEn, titleZh, contentEn, contentZh, category, imageUrl, createdAt, updatedAt

5. **StudyWord** - 学习词汇表（修习页面用）
   - id, word, meaning, pronunciation, example, category, createdAt, updatedAt

6. **StudySentence** - 学习句子表（修习页面用）
   - id, contentZh, contentEn, pinyin, category, createdAt, updatedAt

7. **News** - 新闻表
   - id, title, content, source, category, imageUrl, url, publishedAt, createdAt, updatedAt

8. **PracticeLog** - 练习记录表
   - id, userId, score, mode, createdAt, updatedAt

9. **MistakeBook** - 错题本表
   - id, userId, word, context, createdAt, updatedAt

10. **UserProgress** - 用户学习进度表
    - id, userId, category, contentType, contentId, isLearned, learnedAt, createdAt, updatedAt

11. **UserStudyStats** - 用户学习统计表
    - id, userId, date, wordsLearned, sentencesLearned, totalLearned, studyTime, createdAt, updatedAt

12. **CheckIn** - 签到记录表
    - id, userId, date, points, createdAt

13. **VerificationCode** - 验证码表
    - id, email, code, type, expiresAt, createdAt

14. **CrawlerLog** - 爬虫日志表
    - id, source, status, articleCount, error, startedAt, completedAt, createdAt, updatedAt

15. **CrawlerConfig** - 爬虫配置表
    - id, name, url, selector, category, enabled, interval, lastRunAt, createdAt, updatedAt

16. **ExamResult** - 考试结果表（drill 功能用）
    - id, userId, score, details (JSON), aiFeedback, createdAt, updatedAt

### 执行步骤
1. 创建 `prisma/recreate-all-tables.sql` 文件
2. 包含所有表的 CREATE TABLE 语句
3. 包含示例数据 INSERT 语句
4. 用户确认后在数据库中执行
