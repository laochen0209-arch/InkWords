# 网站问题修复与深度优化计划

## 🔴 紧急问题修复

### 1. 修复 API Route 的缓存导入错误
- **问题**：`app/api/user/stats/route.ts` 导入了客户端缓存工具到服务器端 API
- **修复**：移除服务器端 API 中的 `@/lib/cache` 导入，缓存只在客户端使用

### 2. 优化 Home 页面重复 API 调用
- **问题**：从日志看到 `/api/checkin` 和 `/api/user/me` 被重复调用很多次
- **修复**：为 Home 页面添加去重逻辑和缓存

## 🚀 性能优化（第二阶段）

### 3. 继续清理 console.log
- 在 20+ 个文件中还有 console.log
- 为关键文件添加条件化日志

### 4. Home 页面优化
- 直接使用 AuthContext 的数据，避免重复调用 API
- 添加防抖机制

### 5. Checkin 页面优化
- 同样减少重复 API 调用

### 6. 检查其他页面
- Library、Study、Practice 等页面的性能检查

### 7. 添加 React.memo 优化
- 为频繁渲染的组件添加 memo
- 优化重渲染性能
