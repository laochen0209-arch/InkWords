
## 问题分析

账号设置页面的头像、昵称、修改密码功能无法正常显示使用，原因如下：

### 1. 后端 API 问题
- `/api/user/update` 和 `/api/user/change-password` 使用了单例模式的 Supabase 客户端
- 但环境变量检查不够严格，如果 `SUPABASE_SERVICE_ROLE_KEY` 未设置，会回退到 `ANON_KEY`
- 使用 ANON_KEY 会受到 RLS 限制，导致更新失败

### 2. 前端状态更新问题
- `setUserData` 函数参数映射有问题：接收 `name` 和 `avatar`，但存储时映射为 `nickname` 和 `avatarUrl`
- 但 `updateUserProfile` 只更新 AuthContext，没有同步到 localStorage
- 头像上传成功后，页面上的头像显示没有正确更新

### 3. 页面初始化问题
- 页面初始化时从 `getUserData()` 获取数据，但新用户可能没有这个数据
- 没有正确处理 `authUser` 为空的情况

## 修复方案

### 1. 修复后端 API
- 添加严格的环境变量检查
- 确保使用 Service Role Key，否则返回明确的错误
- 添加详细的错误日志

### 2. 修复前端状态管理
- 修复 `setUserData` 调用，确保参数正确映射
- 优化 `useEffect` 初始化逻辑，优先使用 `authUser` 数据
- 确保头像更新后页面立即显示新头像

### 3. 优化用户体验
- 添加更多加载状态提示
- 优化错误提示信息
- 确保修改成功后页面状态立即更新
