## 问题分析

底部导航栏"我的"按钮链接是正确的 `/profile`，但点击后跳转到 `/auth`。

根本原因是：**Profile 页面的 `supabase.auth.getUser()` 返回 null，触发 `redirect('/auth')`**。

## 修复方案

### 1. 修改 `middleware.ts`
在 Middleware 中添加路由保护逻辑：
- 如果访问 `/profile` 且未登录，重定向到 `/auth`
- 如果已登录，正常刷新 Session

### 2. 修改 `app/profile/page.tsx`
- 移除 `redirect('/auth')` 逻辑（middleware 已处理）
- 简化代码，假设用户一定已登录
- 专注于数据获取和渲染

## 修改内容

**middleware.ts**：
```typescript
// 刷新 Session
const { data: { session } } = await supabase.auth.getSession()

// 保护 /profile 路由
if (request.nextUrl.pathname.startsWith('/profile') && !session) {
  return NextResponse.redirect(new URL('/auth', request.url))
}

return response
```

**app/profile/page.tsx**：
- 移除 `if (error || !user) { redirect('/auth') }`
- 直接使用 `user` 数据
