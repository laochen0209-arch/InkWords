# 语言逻辑错误修复计划

## 问题概述
修复以下 4 个页面/组件中的语言显示错误：

## [ ] 任务 1：修复首页"加载中..."显示为中文
- **优先级**: P0
- **文件**: `app/home/page.tsx`
- **问题**: 第 224 行硬编码了中文"加载中..."
- **修复**: 修改为英文"Loading..."
- **成功标准**: 加载状态显示为英文

## [ ] 任务 2：修复落地页登录页面语言显示错误
- **优先级**: P0
- **文件**: `app/login-en/page.tsx`
- **问题**: 无论用户选择学习什么语言，登录页面都显示英文
- **修复**: 
  - 获取 `inkwords_learning_mode` 设置
  - 如果是 "LEARN_CHINESE"，显示中文界面
  - 如果是 "LEARN_ENGLISH"，显示英文界面
- **成功标准**: 
  - 从落地页选择"学习英文"后，登录页面显示中文
  - 从落地页选择"学习中文"后，登录页面显示英文

## [ ] 任务 3：检查并修复底部导航栏语言
- **优先级**: P1
- **文件**: `components/library/bottom-nav-bar.tsx`
- **问题**: "我的"标签可能硬编码为中文
- **修复**: 根据语言设置动态显示
- **成功标准**: 底部导航栏"我的"显示为正确的语言

## 测试要求
- `human-judgement` TR-1: 首页加载时显示 "Loading..." 而不是 "加载中..."
