## 修复计划

### 问题诊断
1. MockExam 表字段名使用驼峰（examType），但前端使用下划线（exam_type）
2. StudySentence 字段名不一致（contentZh vs zh）
3. StudyWord 字段名不一致（example vs example_sentence）
4. 表名大小写问题（MockExam vs mock_exams）

### 修复步骤
1. 修改 SQL 文件，将所有字段改为 snake_case
2. MockExam 表字段重命名：
   - examType → exam_type
   - rewrittenContent → rewritten_content
3. StudySentence 表字段重命名：
   - contentZh → zh
   - contentEn → en
4. StudyWord 表添加字段：
   - example_sentence（兼容前端）
5. 更新完成后的 SQL 脚本

### 执行后
用户需要在数据库中执行 ALTER TABLE 或直接重新创建表
