# 修复 Profile 页面 UI 计划

## 问题分析

从截图可以看到以下问题：

1. **VIP 特权列表布局问题**：
   - 目前是两列布局，但用户希望按照标记的方式居中排列
   - 需要改为单列居中，每项一行

2. **需要删除月度/年度会员按钮**：
   - 图1中红框标记的"月度会员 3.99 USD/月"和"年度会员 39.90 USD/年"按钮需要删除
   - 因为现在已经有了两步式支付流程，不需要在这里显示套餐选择

3. **删除 DEBUG 信息**：
   - 图2中显示的 "DEBUG: isVip=false, is_pro=false, status=null" 需要删除
   - 这个看起来像报错，影响用户体验

4. **字体颜色统一**：
   - 改为金黄色、红色点缀
   - 与网站整体风格统一

## 修改方案

### 1. 修改 app/profile/page.tsx

**删除内容：**
- 删除 DEBUG 信息展示区域
- 删除套餐选择卡片（月度会员/年度会员按钮）
- 删除相关的 plans 配置和 selectedPlan state

**修改内容：**
- VIP 特权列表改为单列居中布局
- 字体颜色改为金黄色（#D4AF37）和红色点缀
- 调整整体样式与网站风格统一

### 2. 修改 DualCheckoutPanel.tsx（如果需要）
- 确保字体颜色与网站风格统一
