## 问题分析

从日志可以看出登录注册返回 500 错误。检查代码后发现：

1. **API 代码** (`send-code/route.ts`, `register/route.ts`) 使用 Prisma 查询数据库
2. **Prisma Schema** 配置了多 schema (`schemas = ["public", "auth"]`)
3. **所有模型** 都有 `@@schema("public")` 标记

## 可能的原因

1. **Prisma Client 未正确生成** - 多 schema 配置需要 Prisma 5.x 以上版本
2. **数据库表不存在** - `User` 和 `VerificationCode` 表可能未创建
3. **Schema 权限问题** - Supabase 对 public schema 的访问权限

## 修复方案

### 方案 1：简化 Prisma Schema（推荐）

移除 `@@schema("public")` 标记，使用默认 schema 配置：

```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
  // 移除 schemas 配置
}

model User {
  // ... 字段
  // 移除 @@schema("public")
}
```

### 方案 2：确保 Prisma 版本兼容

检查 package.json 中的 Prisma 版本是否支持多 schema：
- Prisma 5.0.0+ 才支持 `schemas` 配置

### 方案 3：重新生成 Prisma Client

```bash
npx prisma generate
npx prisma db push
```

## 建议的修复步骤

1. 检查并更新 Prisma 版本
2. 简化 schema 配置（移除多 schema）
3. 重新生成 Prisma Client
4. 同步数据库表结构
