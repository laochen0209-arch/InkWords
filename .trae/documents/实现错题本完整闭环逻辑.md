## 错题本实现计划

### 1. 数据库表结构修改

当前 `mistake_books` 表结构：
- id, userId, word, context, createdAt, updatedAt

**需要修改为适合考试错题的结构：**
```prisma
model MistakeBook {
  id              String   @id @default(cuid())
  userId          String   @map("user_id")
  examType        String   @map("exam_type")     // 考试类型 IELTS/TOEFL等
  sectionType     String   @map("section_type")  // 题型 listening/reading/vocabulary
  questionContent Json       // 完整题目信息(JSON)
  userAnswer      String     @map("user_answer") // 用户错误答案
  correctAnswer   String     @map("correct_answer") // 正确答案
  analysis        String?    // 解析
  createdAt       DateTime   @default(now()) @map("created_at")
  
  @@index([userId])
  @@map("mistake_books")
}
```

### 2. 考试页面修改 (ExamContent.tsx)

在 `handleSubmit` 函数中新增错题入库逻辑：

```typescript
// 提交试卷后，将错题入库
const saveMistakes = async () => {
  const mistakes = [];
  
  exam.sections.forEach(section => {
    section.questions.forEach(question => {
      const userAns = userAnswers[section.type]?.[question.id] || '';
      const isCorrect = userAns.trim().toLowerCase() === question.answer.trim().toLowerCase();
      
      if (!isCorrect) {
        mistakes.push({
          userId,
          examType: exam.exam_type,
          sectionType: section.type,
          questionContent: question,  // 完整题目信息
          userAnswer: userAns,
          correctAnswer: question.answer,
          analysis: question.analysis
        });
      }
    });
  });
  
  if (mistakes.length > 0) {
    await supabase.from('mistake_books').insert(mistakes);
  }
};
```
