# 修改 DualCheckoutPanel UI 计划

## 问题分析

从截图可以看到以下问题：

1. **会员功能介绍文字靠左**：VIP 特权列表（无限学习单词和句子、解锁所有图书馆资源等）目前是左对齐，应该居中对齐

2. **价格显示方式需要修改**：
   - 目前直接显示 ￥9.9 和 $3.99，用户可以直接对比人民币和美元价格
   - 应该改为：先显示两个支付方式按钮（微信/支付宝 和 Credit Card/PayPal），点击后才显示该支付方式的月费/年费选择

3. **字体颜色问题**：
   - 图2显示"由爱发电提供技术支持"和"Powered by Patreon"文字看不清
   - 灰色背景上使用灰色字体，对比度太低
   - 需要与网站整体风格统一

## 修改方案

### 1. 修改 app/profile/page.tsx
- 将 VIP 特权列表的 `grid-cols-2` 改为居中对齐方式
- 或者使用 flex 布局让文字居中

### 2. 重构 DualCheckoutPanel.tsx
改为两步式支付流程：

**第一步：选择支付方式**
- 按钮 A：微信 / 支付宝（爱发电）
- 按钮 B：Credit Card / PayPal（Patreon）
- 不显示价格

**第二步：选择套餐类型（点击支付方式后显示）**
- 月费按钮
- 年费按钮
- 显示对应价格

### 3. 修复字体颜色
- 将副标题文字颜色改为与网站风格统一的可见颜色
- 使用 `text-stone-600` 或更深的颜色确保对比度
- 或者使用金色/主题色点缀

## 实施步骤

1. 修改 profile/page.tsx - VIP 特权列表居中对齐
2. 重构 DualCheckoutPanel.tsx - 两步式支付流程
3. 修复字体颜色对比度问题
4. 检查 TypeScript 错误
5. 提交并推送
