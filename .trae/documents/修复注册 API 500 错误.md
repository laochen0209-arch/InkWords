
## 问题分析

注册 API (`/api/register`) 返回 500 错误，原因是：

1. **根本问题**：`createServerClient` 是异步函数，但代码中是同步调用的
   ```typescript
   const supabase = createServerClient() // ❌ 缺少 await
   ```

2. **需要修复的内容**：
   - 修复 `createServerClient` 的调用方式，添加 `await`
   - 或者改用 `createAdminClient` 使用 Service Role Key 绕过 RLS
   - 添加环境变量检查，提供更清晰的错误信息

## 修复方案

### 方案 1：修复异步调用（推荐）
修改 `app/api/register/route.ts`：
1. 将 `const supabase = createServerClient()` 改为 `const supabase = await createServerClient()`
2. 添加环境变量检查
3. 优化错误处理

### 方案 2：使用 Admin Client（更稳定）
像 `send-code` 一样直接使用 `@supabase/supabase-js` 和 Service Role Key，绕过 RLS 限制。

## 建议采用方案 2
因为：
1. 与 `send-code` 保持一致
2. 避免 RLS 权限问题
3. 服务端 API 应该使用 Service Role Key
