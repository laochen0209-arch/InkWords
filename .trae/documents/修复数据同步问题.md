## 问题分析

### 现象
- 修改头像/昵称成功（图1）
- 返回 profile 页面后恢复旧数据（图2）

### 根本原因
1. `auth-context.tsx` 从 Supabase Auth 获取用户数据（`user_metadata`）
2. 但 API 只更新了数据库，没有更新 Supabase Auth 的 user_metadata
3. 返回 profile 页面时，`auth-context` 重新获取数据，显示 Auth 中的旧数据

### 解决方案

**方案1：修改 auth-context，优先从数据库获取数据（推荐）**
- 修改 `fetchUserProfile` 和 `createBaseUser` 优先使用数据库数据
- 确保数据库是数据源的唯一真相

**方案2：API 同时更新 Supabase Auth user_metadata**
- 已经在 API 中尝试更新，但可能失败
- 需要检查 Admin API 调用

**方案3：修改后强制刷新 auth 状态**
- 调用 `refreshSession()` 重新获取用户数据
- 在 account 页面修改成功后调用

### 执行步骤

1. 修改 `auth-context.tsx`：
   - 优先从数据库获取 name 和 avatar
   - 更新 localStorage 缓存

2. 修改 `account/page.tsx`：
   - 修改成功后调用 `refreshSession()`
   - 确保全局状态同步
