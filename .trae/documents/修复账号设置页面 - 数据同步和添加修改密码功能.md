## 问题分析

1. **数据不同步**：`settings/account` 页面修改的头像/昵称只保存在 localStorage，没有同步到数据库
2. **Profile 页面从数据库读取**：导致显示的是旧数据
3. **缺少修改密码功能**：Account 页面没有密码修改功能

## 修复方案

### 第一步：创建 API 端点

**1. `app/api/user/update/route.ts`**
- 更新 `public.users` 表的 name 和 avatar 字段
- 更新 Supabase Auth user metadata

**2. `app/api/user/change-password/route.ts`**
- 验证当前密码
- 更新数据库 users 表的 password 字段
- 更新 Supabase Auth 用户密码

### 第二步：修改 `app/settings/account/page.tsx`
- 添加密码修改区块（类似登录页的忘记密码）
- 修改头像/昵称保存时调用 API 同步到数据库
- 添加修改密码的 UI：当前密码、新密码、确认新密码

### 第三步：修改 `lib/contexts/auth-context.tsx`
- 添加 updatePassword 方法

### 修改密码流程
1. 输入当前密码验证身份
2. 输入新密码和确认密码
3. 调用 API 更新密码
4. 成功后提示用户重新登录
