问题分析：

`ExamContent.tsx` 中的 `handlePracticeComplete` 函数直接使用 `supabase.auth.getSession()` 获取 session，但存在以下问题：

1. **未使用 useAuth hook**：组件没有使用项目中已有的 `useAuth` hook，该 hook 已经处理了会话初始化和监听
2. **直接调用 getSession()**：可能导致在某些情况下（cookie 问题、时序问题）获取不到 session
3. **没有错误重试机制**：获取 session 失败时直接提示登录

修复方案：

1. **导入 useAuth hook**：在 `ExamContent.tsx` 中导入并使用 `useAuth`
2. **使用 auth context 中的用户信息**：通过 `useAuth` 获取已验证的用户信息
3. **添加调试日志**：帮助排查问题
4. **备选方案**：如果 useAuth 获取不到用户，再尝试 getSession()

修改内容：

* 添加 `import { useAuth } from "@/lib/contexts/auth-context"`

* 在组件中使用 `const { user } = useAuth()`

* 修改 `handlePracticeComplete` 函数，优先使用 `user?.id`

* 添加调试日志帮助排查
