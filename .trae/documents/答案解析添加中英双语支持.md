## 优化目标
为试卷页面的答案解析区域添加中英双语显示，与网站整体双语风格保持一致。

## 当前问题
答案解析目前只有英文：
- "Correct Answer: xxx"
- "No explanation available."

## 优化方案

### 1. 答案解析标题双语
将 "Correct Answer" 改为中英双语格式：
```
正确答案 / Correct Answer: xxx
```

### 2. 解析内容双语
如果 explanation 字段只包含一种语言，保持原样；
如果数据库支持，显示双语格式：
```
中文解析内容
English explanation content
```

### 3. 空状态双语
将 "No explanation available" 改为：
```
暂无解析 / No explanation available
```

### 4. 视觉样式优化
- 中文使用 `font-serif` 衬线字体
- 英文使用默认字体
- 两种语言之间添加适当间距分隔

## 代码修改位置
修改 `QuestionPanel` 组件中的答案解析部分（第 96-107 行）
