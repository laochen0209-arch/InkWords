# 修复邮箱注册功能

## 当前问题

从代码分析发现：

1. **`.env` 文件中的邮件变量未设置**：
   ```
   EMAIL_SERVER_HOST (比如 smtp.163.com)
   EMAIL_SERVER_PORT (比如 465)
   EMAIL_SERVER_USER (你的发件邮箱)
   EMAIL_SERVER_PASSWORD (邮箱授权码，不是登录密码)
   EMAIL_FROM (发件人地址)
   ```
   这些都是示例文本，不是真实值。

2. **`/api/send-code/route.ts` 是测试模式**：
   - 验证码只输出到控制台，不发送真实邮件
   - 用户需要在服务器日志中查看验证码

## 修复计划

### 方案 1：使用真实邮件服务（推荐）

需要用户提供：
- SMTP 服务器地址（如 smtp.163.com, smtp.gmail.com）
- SMTP 端口（如 465, 587）
- 发件邮箱地址
- 邮箱授权码/密码
- 发件人名称

然后：
1. 安装 nodemailer 包
2. 配置 SMTP 客户端
3. 修改 `/api/send-code/route.ts` 发送真实邮件

### 方案 2：继续使用测试模式（临时方案）

在测试模式下：
1. 修改前端，显示提示信息："请查看服务器控制台获取验证码"
2. 或者将验证码显示在页面上（仅用于测试）

## 建议

建议采用 **方案 1**，配置真实的邮件服务。用户需要提供邮件服务商的信息。

常用的邮件服务商：
- **163邮箱**: smtp.163.com, 端口 465
- **QQ邮箱**: smtp.qq.com, 端口 465
- **Gmail**: smtp.gmail.com, 端口 587
- **Outlook**: smtp.office365.com, 端口 587
