## 实现计划

### 一、目标

实现完整的考试提交、阅卷、反馈闭环，包括数据库存储、后端阅卷逻辑和前端成绩报告页。

### 二、任务分解

#### 1. 数据库变更 (Prisma)

在 schema.prisma 中新增 ExamResult 模型：

```prisma
model ExamResult {
  id          String   @id @default(cuid())
  userId      String
  examType    String   // IELTS/TOEFL/CET-4等
  score       Int      // 总分
  maxScore    Int      // 满分
  details     Json     // 各部分得分和错题详情
  aiFeedback  String?  // AI评语
  createdAt   DateTime @default(now())
  
  @@index([userId])
  @@index([createdAt])
}
```

#### 2. 后端接口升级 (/api/practice/submit)

修改提交接口：

* 接收试卷数据、用户答案

* 客观题自动评分（比对正确答案）

* 主观题调用 AI API 评分（0-10分 + 评语）

* 将结果写入 ExamResult 表

* 返回成绩摘要

#### 3. 前端升级

* 修改 ExamContent.tsx 提交逻辑

* 新建成绩报告页 /practice/drill/result/\[id]

* 展示：总分、各部分得分、错题解析、AI建议

### 三、文件变更清单

1. **prisma/schema.prisma** - 新增 ExamResult 模型
2. **app/api/practice/submit/route.ts** - 升级提交接口
3. **app/practice/drill/ExamContent.tsx** - 修改提交逻辑
4. **app/practice/drill/result/\[id]/page.tsx** - 新建成绩报告页
