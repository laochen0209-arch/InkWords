## 性能优化分析

### 发现的问题

1. **字体加载**
   - 加载两种中文字体（思源宋体 + 思源黑体）
   - 字体文件较大，可能影响首屏加载

2. **第三方脚本**
   - Lemon.js 加载没有 defer/async
   - TidioProvider 可能加载额外脚本

3. **图片优化**
   - 背景图片可能过大
   - 缺少图片懒加载

4. **资源预加载**
   - 缺少关键资源预加载
   - 没有 DNS 预解析

### 优化方案

#### 1. 字体优化
- 使用 `font-display: optional` 避免字体加载阻塞
- 添加字体预加载链接
- 考虑使用系统字体作为 fallback

#### 2. 脚本优化
- Lemon.js 使用 `defer` 策略
- 延迟加载非关键脚本

#### 3. 图片优化
- 背景图片使用 WebP 格式
- 添加图片懒加载

#### 4. 资源预加载
- 添加 DNS 预解析
- 预加载关键资源

### 执行步骤
1. 优化 layout.tsx 字体和脚本加载
2. 添加预加载链接
3. 优化背景图片
4. 验证优化效果
