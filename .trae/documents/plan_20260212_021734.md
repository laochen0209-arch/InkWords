## 深色模式背景修复计划

### 问题根源
各页面使用不同的背景实现方式，导致深色模式下背景亮度不一致：
- 部分页面使用 `ink-landscape-bg` 类
- 部分页面使用内联 `backgroundImage` 样式
- 深色模式 CSS 覆盖优先级不足

### 修复方案

**修改 `globals.css` 文件**，增强深色模式背景覆盖：

1. **增强 `ink-landscape-bg` 类的深色模式样式**
   - 添加 `.dark .ink-landscape-bg` 规则，设置深色背景和降低图片透明度

2. **增强 `body::before` 和 `body::after` 的深色模式样式**
   - 提高优先级，确保覆盖所有页面的背景

3. **添加针对固定背景图片的深色模式覆盖**
   - 添加 `.dark [style*="background-image"]` 规则
   - 添加 `.dark .fixed.inset-0` 规则

4. **统一深色模式背景色**
   - 使用 `#0a0a0a` 作为主背景色
   - 背景图片透明度降低到 0.05

### 涉及文件
- `app/globals.css` - 增强深色模式样式

### 预期效果
所有页面在深色模式下将呈现与 `/checkin` 页面一致的深色背景效果。
