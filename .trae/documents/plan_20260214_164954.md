
# 优化"我的"页面性能

## 发现的性能问题

### 1. **重复获取用户数据**
- AuthContext 已经获取了用户数据
- Profile 页面又重新调用 `supabase.auth.getUser()` 和查询 `users` 表
- 造成了重复的网络请求

### 2. **AuthContext 数据不完整**
- AuthContext 缺少 `study_daily_count`, `library_daily_count`, `practice_tickets` 字段
- 导致 Profile 页面需要额外查询

### 3. **复杂的加载状态管理**
- 有 `authLoading` 和 `loading` 两个独立的加载状态
- 有多个 useEffect 相互依赖

## 优化方案

### 第一步：增强 AuthContext
- 修改 `auth-context.tsx`，获取完整的用户数据（包括学习统计）
- 一次性获取所有需要的字段

### 第二步：简化 Profile 页面
- 直接使用 AuthContext 提供的数据
- 移除重复的 `fetchUserData` 函数
- 简化加载状态管理

### 第三步：优化渲染
- 减少不必要的重新渲染
- 使用骨架屏改善用户体验

## 需要修改的文件
1. `lib/contexts/auth-context.tsx` - 增强用户数据获取
2. `app/profile/page.tsx` - 简化数据获取逻辑
