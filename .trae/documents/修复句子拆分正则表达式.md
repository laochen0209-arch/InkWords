## 问题分析

用户需要按句子拆分（使用句号、问号、感叹号），但要排除缩写中的点号（如 U.S.）。

## 解决方案

使用 Negative Lookbehind 来排除单字母缩写后的点号：

```typescript
const splitBySentence = (text: string): string[] => {
  // 先保护常见的缩写（U.S., Dr., Mr., Mrs., Ms., Prof., etc.）
  const protectedText = text
    .replace(/U\.S\./g, 'U[DOT]S[DOT]')
    .replace(/U\.K\./g, 'U[DOT]K[DOT]')
    .replace(/Dr\./g, 'Dr[DOT]')
    .replace(/Mr\./g, 'Mr[DOT]')
    .replace(/Mrs\./g, 'Mrs[DOT]')
    .replace(/Ms\./g, 'Ms[DOT]')
    .replace(/Prof\./g, 'Prof[DOT]')
    .replace(/Sr\./g, 'Sr[DOT]')
    .replace(/Jr\./g, 'Jr[DOT]')
    .replace(/St\./g, 'St[DOT]')
    .replace(/Ave\./g, 'Ave[DOT]')
    .replace(/Blvd\./g, 'Blvd[DOT]')
    .replace(/Rd\./g, 'Rd[DOT]')
    .replace(/No\./g, 'No[DOT]')
    .replace(/vs\./g, 'vs[DOT]')
    .replace(/etc\./g, 'etc[DOT]')
    .replace(/i\.e\./g, 'i[DOT]e[DOT]')
    .replace(/e\.g\./g, 'e[DOT]g[DOT]')
    .replace(/a\.m\./g, 'a[DOT]m[DOT]')
    .replace(/p\.m\./g, 'p[DOT]m[DOT]')
  
  // 按句子拆分（句号、问号、感叹号）
  const sentences = protectedText
    .split(/([.!?]+["']?\s+)/)
    .map(s => s.trim())
    .filter(s => s.length > 0)
  
  // 合并拆分后的句子
  const result: string[] = []
  for (let i = 0; i < sentences.length; i += 2) {
    const sentence = sentences[i] + (sentences[i + 1] || '')
    if (sentence.trim()) {
      result.push(sentence.trim())
    }
  }
  
  // 恢复缩写
  return result.map(s => 
    s.replace(/\[DOT\]/g, '.')
  )
}
```
