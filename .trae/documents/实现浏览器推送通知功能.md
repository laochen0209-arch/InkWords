实现完整的浏览器推送通知功能，包括：

1. **Service Worker** (`public/sw.js`)

   * 监听 push 事件接收推送消息

   * 显示系统通知

   * 处理通知点击事件

2. **通知管理 Hook** (`lib/hooks/use-notifications.ts`)

   * 请求浏览器通知权限

   * 注册/取消 Service Worker

   * 订阅/取消订阅推送

   * 保存订阅到数据库

3. **API 路由**

   * `POST /api/notifications/subscribe` - 保存订阅

   * `POST /api/notifications/unsubscribe` - 取消订阅

   * `POST /api/notifications/send` - 发送测试通知

   * `GET /api/notifications/status` - 获取通知状态

4. **数据库表** (Supabase)

   * `push_subscriptions` 表存储用户订阅信息

5. **修改设置页面** (`components/profile/settings-list.tsx`)

   * 集成真实的通知开关

   * 请求浏览器权限

   * 保存用户偏好

6. **定时任务** (可选)

   * 学习提醒（每天固定时间）

   * 签到提醒

技术栈：

* Web Push API

* Service Worker

* Supabase 数据库存储订阅

* Next.js API Routes
