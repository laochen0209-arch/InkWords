## 问题
[profile-header.tsx](file:///g:/trea/jiaoben/inkwords/components/profile/profile-header.tsx#L36-L40) 中的用户统计数据（已学单词、学习天数、准确率）是硬编码的占位值（128、15、92%），导致新注册用户也显示虚假数据。

## 修复步骤
1. 检查 `useAuth` hook 中是否有用户统计数据字段
2. 如果没有，查看用户表结构，确认是否有相关统计字段
3. 修改 [profile-header.tsx](file:///g:/trea/jiaoben/inkwords/components/profile/profile-header.tsx)，将硬编码值替换为真实数据或 API 调用
4. 如果没有现成的数据源，创建 API 或 Hook 获取用户真实统计数据
5. 新用户默认显示 0 值

## 预期结果
- 新注册用户显示：已学单词 0、学习天数 0、准确率 0% 或 "--"
- 有学习记录的用户显示真实的统计数据
