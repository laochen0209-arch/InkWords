## 当前问题
答题页面只支持单选题（choice / true_false），需要升级支持 7 种题型。

## 升级方案

### 1. 修改 Question 接口
添加 question_type 字段，支持：choice, true_false, fill_blank, matching, multi_choice, short_answer, essay

### 2. 修改答案状态管理
从 `string | null` 改为 `string | string[] | null`，支持不同答案格式

### 3. 根据题型渲染不同界面

| 题型 | 渲染方式 | 答案格式 |
|------|----------|----------|
| choice / true_false | 单选按钮（现有逻辑） | string |
| multi_choice | Checkbox 多选 | string[] |
| fill_blank / short_answer | `<input type="text" />` | string |
| essay | `<textarea>` 大文本框 | string |
| matching | 简化版下拉菜单匹配 | string |

### 4. 修改 handleAnswer
- 根据题型验证答案是否有效
- multi_choice 需要至少选一项
- fill_blank/short_answer/essay 需要非空
- 提交时保持答案原格式（字符串或数组）

### 5. 修改答案验证逻辑
- choice/true_false: 直接字符串比较
- multi_choice: 数组排序后比较
- 其他: 字符串比较

## 文件修改
`app/practice/drill/[examId]/page.tsx`

## 预期结果
- 单选题：保持现有交互
- 多选题：显示复选框，可选多个
- 填空/简答：文本输入框
- 写作：大文本域
- 配对题：简化下拉菜单
