## 修复错题本功能

### 问题
练习提交时未将错题保存到 `mistake_books` 表，导致错题本永远为空。

### 解决方案

**修改文件: `app/api/practice/submit/route.ts`**

在评分完成后，将错题写入 `mistake_books` 表：

```typescript
// 保存错题到错题本
for (const section of details.sections) {
  for (const wrong of section.wrongAnswers) {
    await prisma.mistakeBook.create({
      data: {
        userId,
        examType: examData.examType,
        sectionType: section.type,
        questionContent: {
          id: wrong.questionId,
          type: 'multiple_choice', // 或根据实际情况
          stem: wrong.stem,
          answer: wrong.correctAnswer,
          analysis: wrong.analysis
        },
        userAnswer: wrong.userAnswer,
        correctAnswer: wrong.correctAnswer,
        analysis: wrong.analysis
      }
    })
  }
}
```

### 预期效果
- 用户完成练习后，错题自动保存到错题本
- 错题本页面能正确显示用户的错题记录
