## 问题分析

### 问题 1：词汇运用填空题题目没有正常显示
- 当前代码使用 `question.stem` 显示题目
- 但后端返回的数据可能使用 `content` 字段
- 需要兼容两种字段名

### 问题 2：查看解析时中英文解析没有正常显示
- 当前解析显示逻辑混乱，依赖 `analysis` 字段是否包含中文
- 没有优先使用 `analysis_cn` 和 `analysis_en` 独立字段
- 当 `analysis` 为空时，解析区域完全空白

## 修复方案

### 修复 1：题目显示兼容
在 `ExamContent.tsx` 的 `renderQuestion` 函数中，修改题目渲染逻辑：
```typescript
// 兼容 stem 和 content 字段
const questionText = question.stem || question.content || '';
<h3 className="font-medium text-ink-black">{questionText}</h3>
```

### 修复 2：解析显示逻辑重写
重写解析区域的显示逻辑，优先使用独立的双语字段：
```typescript
// 数据准备
const analysisEn = question.analysis_en || question.analysis;
const analysisCn = question.analysis_cn;
const hasEn = analysisEn && analysisEn.trim().length > 0;
const hasCn = analysisCn && analysisCn.trim().length > 0;
const hasLegacy = question.analysis && question.analysis.trim().length > 0;

// 显示逻辑
{hasEn && (
  <div>英文解析: {analysisEn}</div>
)}
{hasCn && (
  <div>中文解析: {analysisCn}</div>
)}
{!hasEn && !hasCn && hasLegacy && (
  <div>解析: {question.analysis}</div>
)}
```

### 修复 3：类型定义更新
更新 `Question` 接口，添加 `content` 和 `analysis_en` 字段：
```typescript
interface Question {
  // ... 其他字段
  stem?: string;  // 改为可选
  content?: string;  // 新增兼容字段
  analysis_en?: string;  // 新增英文字段
  // ...
}
```
